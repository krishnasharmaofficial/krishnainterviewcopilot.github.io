A stealthy, high-speed, real-time interview assistant built for mobile browsers. This tool listens to your interview questions and provides structured, senior-level technical answers using the Groq Llama 3.3 API.

"Use it and crack it 🍾" — Krishna Sharma

✨ Key Features

Zero-Latency AI: Powered by Groq for responses in under 1.5 seconds.

Hands-Free Operation: Manual "Start/Stop" voice-to-text capture using the Web Speech API.

Executive IDE UI: A premium, dark-mode professional dashboard designed for quick mobile reading, featuring pure black backgrounds and high-contrast yellow code snippets.

Context-Aware (PDF/Word): Upload your resume (.pdf, .docx, .doc) using the built-in parsers. The AI aligns its persona and answers directly to your specific professional history.

Phonetic Autocorrect: Aggressively maps bad speech-to-text transcriptions to the proper technical domain (e.g., "hoops" -> "OOPs", "rough" -> "ref", "zammel" -> "XAML").

Follow-up Memory: Remembers the last few turns of the conversation for seamless follow-up questions and context continuity.

Export to Word: Save your entire interview transcript as a structured .doc file.

Privacy First: Your API keys and resume data are stored exclusively in your browser's localStorage. Zero-server footprint.

🛠️ Getting Started

1. Prerequisites

A Groq API Key (Get one for free at console.groq.com).

A mobile browser (Chrome or Safari) with Microphone permissions enabled.

Your resume in PDF or Word format to feed the knowledge base.

🚀 Usage Tips

Placement: Prop your phone horizontally under your monitor so it stays comfortably in your eye-line.

The "Senior" Tone: The AI is tuned to provide highly accurate, objective, and authoritative bullet points tailored specifically to your domain.

Manual Control: Tap Start Capture when the interviewer begins speaking and Stop & Process as soon as they finish to trigger the lightning-fast response.

Code Snippets: The AI will only output code if explicitly asked. It generates a single, highly compressed code block to save precious mobile screen real estate.

🔒 Security Note

This application communicates directly with the Groq API. Your API Key and parsed resume data are never sent to any intermediate server; they stay safely on your device.
